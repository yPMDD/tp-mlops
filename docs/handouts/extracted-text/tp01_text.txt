TP 1 — Découvrir la boîte à outils MLOps
Durée : 2 h · Partie 2 du cours · binôme de 2




 Ce premier TP installe la chaîne d'outils qui servira dans les onze TP suivants, puis fait toucher du doigt les trois
 fonctions d'une boîte à outils MLOps : le suivi des exécutions, la gestion des versions de modèles et l'automatisation
 des enchainements. Version Windows : toutes les commandes sont écrites pour PowerShell 5.1 ou 7, livré avec
 Windows 10 et 11. Ouvrez « Windows PowerShell », jamais l'invite de commandes cmd.exe. Les blocs @' ... '@ sont
 des here-strings : le marqueur de fermeture '@ doit impérativement se trouver en début de ligne, sans espace
 devant, et le bloc entier se colle en une seule fois.


 Objectifs pédagogiques
  • Installer et vérifier une chaîne d'outils MLOps complète sur son poste
  • Journaliser une exécution d'entraînement et la retrouver dans une interface web
  • Comparer plusieurs exécutions et sélectionner la meilleure sur une métrique
  • Enregistrer un modèle dans un registre et lui affecter un alias
  • Automatiser l'enchaînement des commandes par un script unique


 Prérequis
  • Python 3.10 ou plus, vérifiable par python --version
  • Git installé et configuré (git config user.name et user.email)
  • Un terminal et un éditeur de code (VS Code conseillé)
  • Environ 2 Go d'espace disque libre


 Installation
 Toutes les commandes de ce TP se lancent depuis le dossier tp-mlops, dans une fenêtre Windows PowerShell
 ouverte sur ce dossier.
 terminal

  mkdir tp-mlops; cd tp-mlops                # dossier de travail du module
  python -m venv .venv                       # environnement Python isole
  .venv\Scripts\Activate.ps1                 # activation (PowerShell)
  pip install --upgrade pip -q
  pip install mlflow dvc scikit-learn pandas numpy joblib
  New-Item -ItemType Directory -Force data, models, src | Out-Null
  mlflow --version                           # verifie l'installation
  dvc --version
  # si Activate.ps1 est refuse par la strategie d'execution :
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned


  RÉSULTAT ATTENDU
  mlflow, version 3.x
  3.6x.x

  L'invite du terminal commence maintenant par (.venv).

 Étape 1 — Générer le jeu de données du module
 Ce jeu de transactions synthétique sera réutilisé dans tous les TP. La graine fixe garantit que toute la promo travaille
 sur exactement les mêmes données.
 terminal

  @'
  import numpy as np, pandas as pd
  rng = np.random.default_rng(7)                 # graine fixe : meme jeu pour toute la promo
  n = 5000                                       # nombre de transactions
  montant = np.round(rng.lognormal(6.2, 1.1, n), 2)     # beaucoup de petits montants
  anciennete = rng.integers(0, 120, n)                  # anciennete du client en mois
  freq = rng.poisson(3, n) + 1                          # transactions sur 24 h
  nuit = rng.binomial(1, 0.18, n)                       # paiement entre 0 h et 5 h
  score = 2.2*(np.log10(montant)-3.0) - anciennete/60 + (freq-3)/3 + nuit*1.2
  fraude = ((score + rng.normal(0, 0.35, n)) > 0.6).astype(int)   # etiquette 0 / 1
  pd.DataFrame({'montant': montant, 'anciennete': anciennete, 'freq_24h': freq,
                'nuit': nuit, 'fraude': fraude}).to_csv('data/transactions.csv', index=False)
  print('data/transactions.csv ecrit :', n, 'lignes,', fraude.sum(), 'fraudes')
  '@ | Set-Content -Encoding UTF8 donnees.py
  python donnees.py


  RÉSULTAT ATTENDU
  data/transactions.csv ecrit : 5000 lignes, 568 fraudes



 Étape 2 — Démarrer le serveur de suivi MLflow
 Le serveur stocke les exécutions dans une base SQLite et les artefacts dans un dossier. Laissez ce terminal ouvert
 pendant tout le TP et ouvrez-en un second pour la suite.
 terminal 1

  mlflow server --host 127.0.0.1 --port 5000 `
    --backend-store-uri sqlite:///mlflow.db `
    --default-artifact-root ./mlartifacts


  RÉSULTAT ATTENDU
  [INFO] Listening at: http://127.0.0.1:5000

  Ouvrez cette adresse dans un navigateur : l'interface s'affiche, sans experimentation.


 Si ça coince : les versions recentes de MLflow refusent un stockage sur simple dossier (./mlruns). Le paramètre
 sqlite:///mlflow.db est obligatoire.
 Si ça coince : si le navigateur affiche « Refused to exécute script ... MIME type ('text/plain') », le registre Windows associe
 un mauvais type aux fichiers .js. Corrigez-le sans droits administrateur : New-Item -Path 'HKCU:\Software\Classes\.js'
 -Force ; Set-ItemProperty -Path 'HKCU:\Software\Classes\.js' -Name 'Content Type' -Value 'text/javascript'. Fermez tous les
 terminaux, rouvrez-en un, relancez le serveur et rechargez la page avec Ctrl+F5. L'API de suivi, elle, fonctionne déjà : vous
 pouvez enchaîner les étapes suivantes.

  @'
  import sys, mlflow, mlflow.sklearn, pandas as pd
  from sklearn.ensemble import RandomForestClassifier
  from sklearn.model_selection import train_test_split
  from sklearn.metrics import f1_score
  n_estimators = int(sys.argv[1]) if len(sys.argv) > 1 else 300    # 1er argument
  max_depth    = int(sys.argv[2]) if len(sys.argv) > 2 else 12     # 2e argument
  mlflow.set_tracking_uri('http://127.0.0.1:5000')    # serveur de l'etape 2
  mlflow.set_experiment('tp1-decouverte')             # regroupe les executions
  mlflow.sklearn.autolog()                            # capture automatique
  df = pd.read_csv('data/transactions.csv')
  X, y = df.drop(columns='fraude'), df['fraude']      # entrees / cible
  Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25, random_state=42)
  with mlflow.start_run(run_name=f'rf-{n_estimators}-{max_depth}'):
      m = RandomForestClassifier(n_estimators=n_estimators, max_depth=max_depth,
                                  random_state=42).fit(Xtr, ytr)
      f1 = f1_score(yte, m.predict(Xte))
      mlflow.log_metric('f1_test', f1)                # metrique de comparaison
      print('F1 =', round(f1, 4))
  '@ | Set-Content -Encoding UTF8 src/train.py
  python src/train.py 200 8


  RÉSULTAT ATTENDU
  F1 = 0.8549

  Dans l'interface, l'experimentation tp1-decouverte contient une execution
  nommee rf-200-8, avec ses parametres, ses metriques et son modele.

  @'
  import mlflow
  from mlflow import MlflowClient
  mlflow.set_tracking_uri('http://127.0.0.1:5000')

  print('version', mv.version, 'promue en production')
  '@ | python -

 Étape 6 — Recharger le modèle par son alias
 C'est le geste que fera le service d'inférence du TP 10 : il ne connait ni le chemin du fichier, ni le numéro de version.
 terminal 2

  @'
  import mlflow, pandas as pd
  mlflow.set_tracking_uri('http://127.0.0.1:5000')
  m = mlflow.pyfunc.load_model('models:/fraude-tp1@production')   # chargement par ALIAS
  X = pd.DataFrame([{'montant': 8500, 'anciennete': 3, 'freq_24h': 9, 'nuit': 1}])
  print('prediction :', m.predict(X))
  '@ | python -

 Étape 8 — Automatiser l'enchaînement
 Troisième fonction d'une boîte à outils MLOps : ne plus rien taper à la main. Ce script rejoue l'intégralité du TP en
 une commande.
 run_tp1.sh

  @'
  # rejoue l'integralite du TP en une commande
  python donnees.py                           # 1. donnees
  foreach ($p in '100 4', '200 8', '300 12', '500 16', '600 24') {
      $a = $p -split ' '
      python src/train.py $a[0] $a[1]         # 2. serie d'entrainements
  }
  Write-Host 'TP1 termine - consultez http://127.0.0.1:5000'
  '@ | Set-Content -Encoding UTF8 run_tp1.ps1
  .\run_tp1.ps1                               # execution du script


  RÉSULTAT ATTENDU
  Les cinq executions se relancent d'affilee et apparaissent dans l'interface.
  C'est la brique de base de l'automatisation etudiee au TP 2.
