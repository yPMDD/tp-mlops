TP 9 — Conteneuriser un modèle avec Docker et le déployer sur Kubernetes
page 1
Ce TP met en pratique la partie 7 du cours en deux temps. Partie A : vous prenez en main Docker, puis vous
conteneurisez le service de détection de fraude en suivant les six étapes du cours (projet, service, dépendances,
Dockerfile, construction, test). Partie B : vous déployez ce conteneur sur un orchestrateur, Kubernetes, dans un cluster
local créé avec kind : plusieurs copies, une adresse unique, montée en charge, auto-réparation, mise à jour sans
coupure et retour arrière après une version en panne. Le fil rouge reste le même : le dossier de Mme Benali doit donner
une probabilité de 0,8899, sur votre machine, dans Docker et dans Kubernetes.
VERSION WINDOWS
Toutes les commandes sont écrites pour Windows PowerShell (5.1 ou 7), jamais l'invite cmd.exe. Les blocs @' ... '@
écrivent un fichier ou l'envoient à Python : le marqueur de fermeture '@ doit être en tout début de ligne, et le bloc se colle
en entier. Les fichiers sont écrits en -Encoding ascii : l'encodage UTF8 de PowerShell 5.1 ajoute un marqueur
invisible en tête de fichier qui casse la lecture des fichiers YAML et JSON.
Si l'activation de l'environnement est refusée : Set-ExecutionPolicy -Scope Process -ExecutionPolicy
RemoteSigned, puis relancez .venv\Scripts\Activate.ps1.
CE QUI CHANGE DANS CETTE VERSION
Le TP suit désormais le P07 étape par étape, avec les mêmes fichiers. Image de base Python 3.12. Le Dockerfile n'a plus
de commentaires en fin de ligne : Docker ne les accepte pas (un « # » n'est un commentaire qu'en début de ligne).
Nouveau : premières commandes Docker, page /docs, client de test dans le cluster, version en panne et retour arrière.
Toutes les sorties ont été obtenues réellement.

api/main.py
@'
import socket
import joblib
import pandas as pd
from fastapi import FastAPI
from pydantic import BaseModel
 
VERSION = "1.0"                                      # version du service
HOTE = socket.gethostname()                          # nom du conteneur qui repond
modele = joblib.load("models/model.pkl")             # charge une seule fois, au demarrage
 
app = FastAPI(title="API de detection de fraude")
 
 
class Transaction(BaseModel):                        # les 4 entrees attendues
    montant: float
    anciennete: int
    freq_24h: int
    nuit: int
 
 
@app.get("/health")
def health():                                        # le service est-il pret ?
    return {"statut": "ok", "version": VERSION, "hote": HOTE}
 
 
@app.post("/predict")
def predict(t: Transaction):
    X = pd.DataFrame([t.model_dump()])
    p = float(modele.predict_proba(X)[0, 1])
    return {"fraude": p > 0.5, "probabilite": round(p, 4), "version": VERSION, "hote": HOTE}
'@ | Set-Content -Encoding ascii api/main.py
api/client.py (utilisé en partie B)
@'
"""Interroge le Service Kubernetes pendant N secondes et resume les reponses."""
import collections, json, sys, time, urllib.request
 
URL = "http://fraude-api/predict"            # le nom du Service suffit dans le cluster
DUREE = int(sys.argv[1]) if len(sys.argv) > 1 else 10
corps = json.dumps({"montant": 1800, "anciennete": 30, "freq_24h": 4, "nuit": 1}).encode()
par_pod, fin = collections.Counter(), time.time() + DUREE
while time.time() < fin:
    versions, pods, erreurs, t0 = collections.Counter(), set(), 0, time.time()
    while time.time() - t0 < 2:              # un bilan toutes les 2 secondes
        try:
            req = urllib.request.Request(URL, corps, {"Content-Type": "application/json"})
            r = json.load(urllib.request.urlopen(req, timeout=2))
            versions["v" + r["version"]] += 1
            pods.add(r["hote"])
            par_pod[r["hote"]] += 1
        except Exception:
            erreurs += 1
        time.sleep(0.05)
    bilan = dict(versions)
    print(time.strftime("%H:%M:%S"), bilan, "pods:", len(pods), "erreurs:", erreurs, flush=True)
print("reponses par pod :", dict(par_pod))

spec:
  replicas: 2                          # nombre de copies souhaitees
  selector:
    matchLabels:
      app: fraude-api                  # les pods geres : ceux qui portent cette etiquette
  template:                            # modele de chaque pod
    metadata:
      labels:
        app: fraude-api
    spec:
      containers:
        - name: api
          image: fraude-api:1.0        # l'image construite en partie A
          imagePullPolicy: IfNotPresent  # image locale, pas de telechargement
          ports:
            - containerPort: 8000
          lifecycle:
            preStop:                   # avant l'arret : 5 s pour finir les requetes en cours
              exec:
                command: ["sleep", "5"]
          readinessProbe:              # pas de trafic tant que /health ne repond pas
            httpGet:
              path: /health
              port: 8000
          resources:
            requests:                  # reserve pour chaque pod
              cpu: "100m"              # 0,1 coeur
              memory: "256Mi"
            limits:                    # plafond a ne pas depasser
              cpu: "500m"
              memory: "512Mi"
'@ | Set-Content -Encoding ascii k8s/deployment.yaml
